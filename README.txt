ПОРТФОЛИО АЯНЫ АСЫЛБЕКОВОЙ

ЗАПУСК:
1. Распакуйте архив.
2. Откройте папку в Visual Studio Code.
3. Установите расширение Live Server.
4. Нажмите правой кнопкой на index.html → Open with Live Server.

ДОБАВЛЕНИЕ ФОТО БЕЗ КОДА:
Откройте раздел «Галерея» на сайте и нажмите «Добавить фото».
Можно выбрать сразу несколько изображений. Добавленные фото сохраняются
в IndexedDB браузера на текущем устройстве. Их можно удалить кнопкой ×.

ВАЖНО ПРО ФОТО:
Сейчас в галерее стоят демонстрационные фотографии. Замените их на фотографии
Аяны. Фото, добавленные кнопкой, не загружаются на сервер и не появляются
автоматически у посетителей на других устройствах. Для общей онлайн-галереи
позже понадобится облачное хранилище или сервер.

КОНТАКТЫ:
Кнопки Instagram, WhatsApp и Telegram пока являются заглушками.
Добавьте настоящие ссылки, когда они будут готовы.

СОДЕРЖИМОЕ:
index.html — тексты и разделы сайта
css/style.css — оформление
js/main.js — меню, случайный выбор страны и добавление фото
js/globe.js — интерактивный 3D-глобус

Для загрузки 3D-глобуса, шрифтов и демонстрационных фото требуется интернет.
